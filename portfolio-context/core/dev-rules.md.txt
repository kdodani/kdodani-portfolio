# Development Rules

Before making changes:
- do not refactor unrelated files
- do not rename files unless necessary
- do not modify routing structure
- do not modify package dependencies
- do not change build configuration
- do not rewrite global styles unless explicitly requested

When making UI updates:
- modify only the minimum necessary code
- preserve component interfaces
- preserve import structure
- avoid touching unrelated sections

If a change may affect architecture:
- explain before modifying

NEVER:
- redesign unrelated sections
- rewrite copy unless explicitly instructed
- change spacing system globally
- introduce new colors
- replace typography system
- create new animations unless requested
- modify layout hierarchy outside requested section

Always preserve:
- existing design language
- spacing rhythm
- typography consistency
- component architecture
- narrative tone
